# Skai Lama App

This is the Skai Lama web application.

- Frontend hosted on **Netlify**: [View App](https://skai-lama-app.netlify.app/)
- Backend hosted on **Render**.

> Note: The backend is hosted on Render free tier, so the API calls might take a few seconds initially as the server wakes up.

## Tech Stack

- Frontend: React (or your framework)
- Backend: Node.js / Express
- Hosting: Netlify (frontend) & Render (backend)
